# Wallet icons

All assets are exact downloads or decoded embedded icons; none are redrawn.

- phantom.svg: 108x108 SVG with purple rounded square and cream ghost. Extracted from `icon` in https://raw.githubusercontent.com/anza-xyz/wallet-adapter/master/packages/wallets/phantom/src/adapter.ts
- solflare.svg: 50x50 SVG with yellow rounded square and black emblem. Extracted from `icon` in https://raw.githubusercontent.com/anza-xyz/wallet-adapter/master/packages/wallets/solflare/src/adapter.ts
- backpack.png: 151x151 transparent PNG with red Backpack emblem. Exact download: https://raw.githubusercontent.com/coral-xyz/backpack/master/assets/backpack.png

Provenance: Phantom and Solflare files come from Anza's wallet-adapter, whose purpose is wallet integration and selection UI. Repository license is Apache-2.0. Backpack comes from its official coral-xyz/backpack repository; repository license is GPL-3.0. No separate trademark/logo license was established by this asset lookup.

Backpack's official public media kit explicitly offers Backpack brand icons for download: https://backpack.app/media-kit . Its linked Drive folder: https://drive.google.com/drive/folders/1aUyUTIJT2N1Z4IggWQauBoeM6uVJzTzZ?usp=sharing

Use at preserved aspect ratio in a square wallet selection icon slot. Pair each with the exact wallet name.
